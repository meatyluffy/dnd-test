# Побег из Велкинвильва

Пробная глава кооперативного битемапа по вашей кампании «Из Бездны» (Out of the Abyss).
Это браузерная игра на 1–4 игроков по сети. Нарисована в духе Dragon's Crown.

## Как выложить на GitHub Pages

1. Открой репозиторий на GitHub и нажми **Add file → Upload files**.
2. Перетащи туда **всё содержимое** этой папки: `index.html`, `README.md`, `.nojekyll` и папки `assets`, `js`, `lib`. Нажми **Commit changes**.
3. Открой **Settings → Pages**, в разделе *Build and deployment* выбери **Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Нажми **Save**.
4. Через минуту-две игра будет доступна по адресу `https://<твой-логин>.github.io/<репозиторий>/`.

Другой вариант — itch.io: создай проект с типом **HTML** и загрузи `velkynvelve-game.zip`.

Игру можно запустить и без сайта: распакуй архив и дважды щёлкни по `index.html`. Сетевая игра работает и так, но у каждого игрока должна быть копия папки.

## Как играть по сети

- Один игрок нажимает **«Создать комнату»** и отправляет друзьям код из 5 букв.
- Остальные вводят этот код и нажимают **«Войти»**.
- Когда все собрались, хост нажимает **«Начать бой»**. Можно начать и одному.
- Соединение идёт напрямую между игроками (WebRTC), а бесплатный сервер PeerJS нужен только для того, чтобы игроки нашли друг друга.
- Если у кого-то не получается подключиться, установите всей партией Radmin VPN или Tailscale и попробуйте снова.

## Управление

| Действие | WASD-раскладка | Стрелки | Геймпад (Xbox / PS) |
|---|---|---|---|
| Движение | W A S D | ← ↑ → ↓ | левый стик / крестовина |
| Ближний удар | J | X | X / □ |
| Заклинание 1 | K | A | Y / △ |
| Заклинание 2 | L | Z | B / ○ |
| Заклинание 3 | I | C | A / ✕ |
| Заклинание 4 | O | D | LB / L1 |
| Заклинание 5 | U | V | LT / L2 |
| Рывок / уклонение | Пробел | S | RB / R1 (или RT) |

Раскладка выбирается в меню. WASD + J/K/L — распространённая схема в инди-битемапах и файтингах (Scott Pilgrim, 2XKO). Схема со стрелками повторяет TMNT: Shredder's Revenge (X — атака, A — спецприём, S — уклонение). Раскладка геймпада повторяет Streets of Rage 4: X — атака, Y — спецприём.

## Герои

**Лукарис** — фея-друид:
- удар посохом;
- Ледяной кинжал — осколок льда, после попадания взрывается холодом;
- Огонь фей — подсвеченные враги получают на 35% больше урона, аналог преимущества на атаку;
- Лечащее слово — лечит всех рядом и поднимает упавших;
- Лечение ран — сильное лечение касанием;
- Добрая ягода — роняет ягоды, которые лечат;
- Туманный шаг — телепорт;
- Спасение умирающих — поднимает упавших союзников втрое быстрее.

**Сорин** — полуэльф-колдун:
- удар книгой с отбрасыванием;
- Мистический заряд — основная атака;
- Обморожение — замедляет врага и ослабляет его следующую атаку;
- Адское возмездие — пассивка, копится 12 секунд, потом ударившего охватывает пламя: большой урон и поджог.

**Враги:**
- стражи-дроу;
- арбалетчики-дроу — их болты отравляют;
- элитный дроу;
- босс — жрица Ильвара. Бьёт бичом со змеями, плюётся ядом, накладывает магическую Тьму (в ней ваш урон ниже) и зовёт стражу.
