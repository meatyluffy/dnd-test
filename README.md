# Побег из Велкинвильва

Пиксельная JRPG по вашей кампании «Из Бездны» (Out of the Abyss), сделанная в духе Octopath Traveler 2. Играть можно вместе по сети, от 1 до 4 игроков.

## Как запустить

- **По ссылке:** `https://meatyluffy.github.io/dnd-test/`. Ссылка заработает, когда в настройках репозитория будет включён GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
- **С диска:** распакуй архив и дважды щёлкни по `index.html`.

## Сетевая игра

1. Один игрок нажимает «Создать комнату» и отправляет друзьям код из 5 букв.
2. Остальные вводят код и нажимают «Войти».
3. Когда все собрались, хост нажимает «Начать игру».

Каждый игрок управляет своим героем: ходит по локациям и выбирает ему команды в бою. Если играешь один, ведёшь обоих героев.

## Управление

| Действие | Клавиатура | Геймпад (Xbox / PS) |
|---|---|---|
| Ходить, выбирать в меню | WASD / стрелки | левый стик / крестовина |
| Подтвердить, осмотреть | Enter, Пробел, Z, J | A / ✕ |
| Назад | Esc, X, K, Backspace | B / ○ |
| Усиление + / − | E / Q | RB / LB |

Клавиши подтверждения и отмены взяты из классической схемы JRPG на ПК: Enter или Z — подтвердить, Esc или X — назад.

## Боевая система

- **Очерёдность.** Порядок ходов зависит от скорости. Он показан вверху слева.
- **Щиты и слабости.** У каждого врага есть щит и слабости к оружию (посох, книга) или стихиям (огонь, лёд, сила). Пока слабость не найдена, на её месте стоит «?».
- **Пролом.** Каждое попадание в слабость снимает с щита одно очко. Когда щит падает до нуля, наступает ПРОЛОМ: враг пропускает ходы и получает двойной урон.
- **Усиление.** Каждый ход герой получает одно очко усиления (ОУс), всего их может быть до 5. За один ход можно потратить до 3 очков. Атака оружием от этого бьёт несколько раз, заклинания становятся сильнее.

## Заклинания по правилам D&D 5e

**Лукарис:**
- **Ледяной кинжал** — осколок в цель, затем взрыв холода по всем врагам.
- **Огонь фей** — подсвечивает врагов: видны все их слабости, а сами они получают больше урона, как при преимуществе на атаку.
- **Лечащее слово** — лечит союзника и поднимает упавшего.
- **Лечение ран** — сильное лечение.
- **Добрая ягода** — лечение партии в начале каждого хода.
- **Туманный шаг** — следующая атака по Лукарису промахнётся.
- **Спасение умирающего** — заговор: павший союзник встаёт с 1 ед. здоровья.

**Сорин:**
- **Мистический заряд** — каждое очко усиления добавляет ещё один луч, как на высоких уровнях в D&D.
- **Обморожение** — урон холодом и ослабление следующей атаки врага.
- **Адское возмездие** — реакция: кто ударит Сорина, получит урон огнём.
